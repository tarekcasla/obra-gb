# Tablero de obra · Go Building

Dos vistas sobre el mismo dato de Monday:

- **Obra** — qué está frenado, en qué piso y por qué. Para ir al problema sin recorrer la obra.
- **Dirección** — cumplimiento, desvío de fechas, hitos y qué causa más daño.

Datos en `data.json`. Para actualizar: reemplazar ese archivo, correr `python3 build.py` y publicar.
